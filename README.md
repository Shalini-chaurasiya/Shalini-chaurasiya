### 🛠️ what I've been building

**MediTracker** — a medicine reminder system, because forgetting a dose shouldn't cost someone their health. React, Node, Express, MongoDB — JWT auth, automated reminders, an AI chatbot layered on top for support.

**BookAppointment** — a doctor-booking platform that treats scheduling as a real problem worth solving well: dashboards for doctors, real-time state via Context API, a UI that doesn't get in the way.

**AI Smart Trip Planner** — full-stack travel planning with live maps, hotel data, and itinerary building. The kind of project where the backend and the map API had to actually agree with each other.

Each one taught me the same lesson from a different angle: the hard part is rarely the feature. It's the seam between two things that were never meant to talk to each other.
